# Oasis MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the MVP of the Oasis plugin framework — `Oasis.Core` (context tree, reversible effects, GUID service registry, sync events, plugin contract) + `Oasis.Hosting` (in-process loader + `THost` with dependency activation) — that compiles on Delphi 13, passes DUnitX tests, and runs a console demo.

**Architecture:** Cordis-philosophy plugin framework. A shared `IContext` holds a GUID-keyed `IServiceRegistry`, an `IEventBus` (emit/serial/waterfall), and per-plugin `IEffectScope` "fibers" for reversible side-effects. Plugins (class `IPlugin` or closure) mount on the shared context; dependencies declared as GUID arrays are resolved at runtime via a pending-queue + rescan-on-register mechanism. An `IPluginLoader` abstraction (in-process first) feeds `THost`.

**Tech Stack:** Delphi 10.4+ (built/tested on **Delphi 13 Florence**), DUnitX, pure RTL (no third-party deps in MVP). OmniThreadLibrary and BPL loader are phase 2/3 (not in MVP).

## Spec Corrections During Planning

Three refinements to the approved spec, surfaced during planning (review before execution):

1. **Isolation model: fiber, not per-plugin fork (MATERIAL).** The spec said "Plugin = Fork + run in child context." That breaks cross-plugin DI: a service provided on a child context is invisible to sibling plugins (sibling lookup walks up to root, not sideways). Cordis uses a **shared context + per-plugin effect scope ("fiber")**. We adopt that: plugins mount on a shared context (shared service registry → DI works naturally), each plugin's reversible side-effects are tracked in its own `IEffectScope` so it can unload independently. `Fork` is retained as an optional sub-scoping primitive (genuine shadowing/bubbling), not as the plugin isolation mechanism.

2. **`IPlugin` co-located with `IContext`.** `IContext.Plugin(IPlugin)` and `IPlugin.Apply(IContext)` are mutually recursive interface references → impossible to split across two units without a forbidden interface-section circular `uses`. Both interfaces live in `Oasis.Context.pas`; the implementation helper (`TOasisPlugin` base class) lives in `Oasis.Plugin.pas`.

3. **No generic methods on interfaces.** `IServiceRegistry` is non-generic (`Get(AGUID): IInterface`, raises `EOasisServiceNotFound`). The generic convenience `TContext.GetService<T: IInterface>: T` lives on the concrete class.

4. **Dependency ordering is runtime-resolved, not upfront topo-sort.** With service-GUID deps (not plugin-to-plugin), a static topological sort is impossible (we don't know which plugin provides which GUID until it runs). The pending-queue + **rescan-on-register** mechanism is what actually resolves order and satisfies acceptance criterion 4. "Topo sort" from the spec collapses to: "activate immediately if deps already satisfied; else queue; rescan on every registration." `EOasisDependencyCycle` is retained but a genuine cycle manifests as plugins stuck in pending after Start — reported via `EV_HOST_PLUGIN_FAILED`/`FailedPlugins`, not a hard raise.

```pascal
unit Oasis.Errors;

{ Oasis framework - exception hierarchy. Aggregated failures store message
  strings (not Exception objects) to avoid object-lifetime headaches. }

interface

uses
  System.SysUtils;

type
  EOasisError = class(Exception);

  EOasisServiceNotFound = class(EOasisError);

  EOasisDependencyCycle = class(EOasisError)
  strict private
    FCyclePath: string;
  public
    constructor Create(const AMessage, ACyclePath: string);
    property CyclePath: string read FCyclePath;
  end;

  EOasisPluginActivateError = class(EOasisError)
  strict private
    FPluginName: string;
  public
    constructor Create(const APluginName, AInnerMessage: string);
    property PluginName: string read FPluginName;
  end;

  { Base for aggregated multi-failure errors (dispose / event dispatch). }
  EOasisAggregateError = class abstract (EOasisError)
  strict private
    FMessages: TArray<string>;
  protected
    constructor Create(const AIntro: string; const AMessages: TArray<string>);
  public
    property Messages: TArray<string> read FMessages;
  end;

  EOasisDisposeError = class(EOasisAggregateError)
  public
    constructor Create(const AMessages: TArray<string>);
  end;

  EOasisEventError = class(EOasisAggregateError)
  public
    constructor Create(const AMessages: TArray<string>);
  end;

  EOasisLoaderError = class(EOasisError);

implementation

{ EOasisDependencyCycle }

constructor EOasisDependencyCycle.Create(const AMessage, ACyclePath: string);
begin
  inherited Create(AMessage);
  FCyclePath := ACyclePath;
end;

{ EOasisPluginActivateError }

constructor EOasisPluginActivateError.Create(const APluginName, AInnerMessage: string);
begin
  if AInnerMessage <> '' then
    inherited CreateFmt('Plugin "%s" failed to activate: %s', [APluginName, AInnerMessage])
  else
    inherited CreateFmt('Plugin "%s" failed to activate', [APluginName]);
  FPluginName := APluginName;
end;

{ EOasisAggregateError }

constructor EOasisAggregateError.Create(const AIntro: string;
  const AMessages: TArray<string>);
var
  LBuilder: TStringBuilder;
  LMsg: string;
begin
  LBuilder := TStringBuilder.Create;
  try
    LBuilder.Append(AIntro);
    for LMsg in AMessages do
      LBuilder.Append(#10).Append('  - ').Append(LMsg);
    inherited Create(LBuilder.ToString);
  finally
    LBuilder.Free;
  end;
  FMessages := AMessages;
end;

{ EOasisDisposeError }

constructor EOasisDisposeError.Create(const AMessages: TArray<string>);
begin
  inherited Create('One or more disposers raised during teardown:', AMessages);
end;

{ EOasisEventError }

constructor EOasisEventError.Create(const AMessages: TArray<string>);
begin
  inherited Create('One or more event listeners raised:', AMessages);
end;

end.
```

### Step 1.5 — Write `Oasis.Effects.pas` (make tests pass)

```pascal
unit Oasis.Effects;

{ Oasis framework - reversible effect scopes. A scope is a LIFO stack of cleanup
  callbacks. Dispose pops in reverse order. A cleanup raising does NOT abort the
  rest; failures are aggregated into EOasisDisposeError. Manual early dispose via
  the returned TDisposer is idempotent and claims the entry so Dispose won't
  double-run it. }

interface

uses
  System.SysUtils, System.SyncObjs, System.Generics.Collections,
  Oasis.Types, Oasis.Errors;

type
  IEffectScope = interface
    ['{A1B2C3D4-E5F6-4A7B-8C9D-0E1F2A3B4C5D}']
    function IsActive: Boolean;
    { Run AEffect, push its returned cleanup. Returns the (idempotent) disposer. }
    function Add(const AEffect: TEffectFn): TDisposer;
    { Push an already-existing cleanup. Returns the (idempotent) disposer. }
    function AddCleanup(const ACleanup: TDisposer): TDisposer;
    { Hold an interface reference until the scope disposes. }
    procedure AddDisposable(AObj: IInterface);
    procedure Dispose;
  end;

  TEffectScope = class(TInterfacedObject, IEffectScope)
  private type
    { Each pushed cleanup is wrapped so manual early-dispose and Dispose never
      double-run it. Claim() atomically marks the entry as taken. }
    TEntry = class
    public
      Cleanup: TDisposer;
      Done: Boolean;
      constructor Create(ACleanup: TDisposer);
    end;
  strict private
    FLock: TCriticalSection;
    FStack: TStack<TEntry>;
    FDisposed: Boolean;
    function Claim(AEntry: TEntry): Boolean;
    procedure PushEntry(AEntry: TEntry);
  public
    constructor Create;
    destructor Destroy; override;
    function IsActive: Boolean;
    function Add(const AEffect: TEffectFn): TDisposer;
    function AddCleanup(const ACleanup: TDisposer): TDisposer;
    procedure AddDisposable(AObj: IInterface);
    procedure Dispose;
  end;

implementation

{ TEffectScope.TEntry }

constructor TEffectScope.TEntry.Create(ACleanup: TDisposer);
begin
  inherited Create;
  Cleanup := ACleanup;
  Done := False;
end;

{ TEffectScope }

constructor TEffectScope.Create;
begin
  inherited Create;
  FLock := TCriticalSection.Create;
  FStack := TStack<TEntry>.Create;
end;

destructor TEffectScope.Destroy;
begin
  Dispose;   // safe: idempotent
  FStack.Free;
  FLock.Free;
  inherited Destroy;
end;

function TEffectScope.IsActive: Boolean;
begin
  Result := not FDisposed;
end;

procedure TEffectScope.PushEntry(AEntry: TEntry);
begin
  FLock.Enter;
  try
    if FDisposed then
    begin
      // already torn down: run immediately and drop, never retain
      if Assigned(AEntry.Cleanup) then AEntry.Cleanup;
      AEntry.Free;
      Exit;
    end;
    FStack.Push(AEntry);
  finally
    FLock.Leave;
  end;
end;

function TEffectScope.Claim(AEntry: TEntry): Boolean;
begin
  FLock.Enter;
  try
    if AEntry.Done then
      Exit(False);
    AEntry.Done := True;
    Result := True;
  finally
    FLock.Leave;
  end;
end;

function TEffectScope.Add(const AEffect: TEffectFn): TDisposer;
var
  LCleanup: TDisposer;
begin
  if Assigned(AEffect) then
    LCleanup := AEffect
  else
    LCleanup := nil;
  Result := AddCleanup(LCleanup);
end;

function TEffectScope.AddCleanup(const ACleanup: TDisposer): TDisposer;
var
  LEntry: TEntry;
begin
  LEntry := TEntry.Create(ACleanup);
  PushEntry(LEntry);
  Result := procedure
            begin
              if Claim(LEntry) and Assigned(LEntry.Cleanup) then
                LEntry.Cleanup;
            end;
end;

procedure TEffectScope.AddDisposable(AObj: IInterface);
begin
  AddCleanup(procedure begin AObj := nil; end);
end;

procedure TEffectScope.Dispose;
var
  LErrors: TArray<string>;
  LFailed: Boolean;
  LEntry: TEntry;
begin
  FLock.Enter;
  try
    if FDisposed then Exit;
    FDisposed := True;
  finally
    FLock.Leave;
  end;

  LFailed := False;
  while True do
  begin
    FLock.Enter;
    try
      if FStack.Count = 0 then Break;
      LEntry := FStack.Pop;
    finally
      FLock.Leave;
    end;
    try
      try
        if Claim(LEntry) and Assigned(LEntry.Cleanup) then
          LEntry.Cleanup;
      finally
        LEntry.Free;
      end;
    except
      on E: Exception do
      begin
        LFailed := True;
        SetLength(LErrors, Length(LErrors) + 1);
        LErrors[High(LErrors)] := E.Message;
      end;
    end;
  end;

  if LFailed then
    raise EOasisDisposeError.Create(LErrors);
end;

end.
```

```pascal
    destructor Destroy; override;
    procedure Register(const AGUID: TGUID; AInstance: IInterface); overload;

    FLock.Leave;
```

```pascal
unit Oasis.Events;

{ Oasis framework - event bus. Emit/Serial are synchronous, in registration
  order, with per-listener fault isolation (failures aggregate into
  EOasisEventError). Waterfall is around-middleware: a listener that does not
  call Next short-circuits the chain. On() attaches auto-unsubscription to an
  IEffectScope so listeners are reclaimed when their owner unloads. Emit bubbles
  to the parent bus (Fork support). }

interface

uses
  System.SysUtils, System.SyncObjs, System.Generics.Collections,
  Oasis.Types, Oasis.Errors, Oasis.Effects;

type
  IEventBus = interface
    ['{C3D4E5F6-A7B8-4C9D-0E1F-2A3B4C5D6E7F}']
    function On(const AEvent: TEventKey; const AHandler: TEventHandler): TDisposer; overload;
    function OnWaterfall(const AEvent: TEventKey;
                         const AHandler: TWaterfallHandler): TDisposer; overload;

    procedure Emit(const AEvent: TEventKey; const AArgs: array of const);
    procedure Serial(const AEvent: TEventKey; const AArgs: array of const);
    { Returns True if the chain reached the end (no veto); False if short-circuited. }
    function  Waterfall(const AEvent: TEventKey; const AArgs: array of const): Boolean;
  end;

  TEventBus = class(TInterfacedObject, IEventBus)
  strict private type
    TListenerKind = (lkEmit, lkWaterfall);
    TListener = record
      Kind: TListenerKind;
      Emit: TEventHandler;
      Waterfall: TWaterfallHandler;
    end;
  strict private
    FLock: TCriticalSection;
    FOwner: IEffectScope;
    FParent: IEventBus;
    FListeners: TObjectDictionary<TEventKey, TList<TListener>>;
    function EnsureList(const AEvent: TEventKey): TList<TListener>;
    procedure AddListener(const AEvent: TEventKey; const AListener: TListener);
  public
    constructor Create(AOwner: IEffectScope; AParent: IEventBus);
    destructor Destroy; override;
    function On(const AEvent: TEventKey; const AHandler: TEventHandler): TDisposer; overload;
    function OnWaterfall(const AEvent: TEventKey;
                         const AHandler: TWaterfallHandler): TDisposer; overload;
    procedure Emit(const AEvent: TEventKey; const AArgs: array of const);
    procedure Serial(const AEvent: TEventKey; const AArgs: array of const);
    function  Waterfall(const AEvent: TEventKey; const AArgs: array of const): Boolean;
  end;

implementation

{ TEventBus }

constructor TEventBus.Create(AOwner: IEffectScope; AParent: IEventBus);
begin
  inherited Create;
  FLock := TCriticalSection.Create;
  FOwner := AOwner;
  FParent := AParent;
  FListeners := TObjectDictionary<TEventKey, TList<TListener>>.Create([doOwnsValues]);
end;

destructor TEventBus.Destroy;
begin
  FListeners.Free;
  FLock.Free;
  inherited Destroy;
end;

function TEventBus.EnsureList(const AEvent: TEventKey): TList<TListener>;
begin
  if not FListeners.TryGetValue(AEvent, Result) then
  begin
    Result := TList<TListener>.Create;
    FListeners.Add(AEvent, Result);
  end;
end;

procedure TEventBus.AddListener(const AEvent: TEventKey; const AListener: TListener);
var
  LList: TList<TListener>;
  LEvent: TEventKey;
begin
  LEvent := AEvent;
  FLock.Enter;
  try
    LList := EnsureList(LEvent);
    LList.Add(AListener);
  finally
    FLock.Leave;
  end;
end;

function TEventBus.On(const AEvent: TEventKey;
  const AHandler: TEventHandler): TDisposer;
var
  LListener: TListener;
  LEvent: TEventKey;
  LSelf: TEventBus;
begin
  LSelf := Self;
  LEvent := AEvent;
  LListener.Kind := lkEmit;
  LListener.Emit := AHandler;
  LListener.Waterfall := nil;
  AddListener(AEvent, LListener);
  // auto-unsubscribe when the owning scope tears down
  if FOwner <> nil then
    FOwner.AddCleanup(
      procedure
      var
        LList: TList<TListener>;
        I: Integer;
      begin
        LSelf.FLock.Enter;
        try
          if LSelf.FListeners.TryGetValue(LEvent, LList) then
          begin
            for I := 0 to LList.Count - 1 do
              if (LList[I].Kind = lkEmit) and (LList[I].Emit = AHandler) then
              begin
                LList.Delete(I);
                Break;
              end;
            if LList.Count = 0 then
              LSelf.FListeners.Remove(LEvent);
          end;
        finally
          LSelf.FLock.Leave;
        end;
      end);
  Result := nil;
end;

function TEventBus.OnWaterfall(const AEvent: TEventKey;
  const AHandler: TWaterfallHandler): TDisposer;
var
  LListener: TListener;
begin
  LListener.Kind := lkWaterfall;
  LListener.Emit := nil;
  LListener.Waterfall := AHandler;
  AddListener(AEvent, LListener);
  if FOwner <> nil then
    FOwner.AddCleanup(
      procedure
      var
        LList: TList<TListener>;
        I: Integer;
      begin
        FLock.Enter;
        try
          if FListeners.TryGetValue(AEvent, LList) then
          begin
            for I := 0 to LList.Count - 1 do
              if (LList[I].Kind = lkWaterfall) and (LList[I].Waterfall = AHandler) then
              begin
                LList.Delete(I);
                Break;
              end;
            if LList.Count = 0 then
              FListeners.Remove(AEvent);
          end;
        finally
          FLock.Leave;
        end;
      end);
  Result := nil;
end;

procedure TEventBus.Emit(const AEvent: TEventKey; const AArgs: array of const);
var
  LErrors: TArray<string>;
  LFailed: Boolean;
  LSnapshot: TList<TListener>;
  LListener: TListener;
begin
  LSnapshot := nil;
  FLock.Enter;
  try
    if FListeners.TryGetValue(AEvent, LSnapshot) then
    begin
      // copy references out so handlers may safely mutate the live list
      LSnapshot := TList<TListener>.Create(LSnapshot);
    end;
  finally
    FLock.Leave;
  end;
  try
    LFailed := False;
    if LSnapshot <> nil then
    try
      for LListener in LSnapshot do
        if LListener.Kind = lkEmit then
        try
          LListener.Emit(AArgs);
        except
          on E: Exception do
          begin
            LFailed := True;
            SetLength(LErrors, Length(LErrors) + 1);
            LErrors[High(LErrors)] := E.Message;
          end;
        end;
    finally
      LSnapshot.Free;
    end;
    if LFailed then
      raise EOasisEventError.Create(LErrors);
  except
    // still bubble to parent even if some listeners failed
    on EOasisEventError do
    begin
      if FParent <> nil then FParent.Emit(AEvent, AArgs);
      raise;
    end;
  end;
  if FParent <> nil then
    FParent.Emit(AEvent, AArgs);
end;

procedure TEventBus.Serial(const AEvent: TEventKey; const AArgs: array of const);
begin
  // Synchronous in Delphi: identical to Emit, kept for API parity with Cordis.
  Emit(AEvent, AArgs);
end;

function TEventBus.Waterfall(const AEvent: TEventKey;
  const AArgs: array of const): Boolean;
var
  LSnapshot: TList<TListener>;
  LIndex: Integer;
  LAborted: Boolean;

  procedure RunFrom(AFrom: Integer);
  var
    I: Integer;
    LNext: TWaterfallNext;
    LListener: TListener;
  begin
    I := AFrom;
    while (I < LSnapshot.Count) and not LAborted do
    begin
      LListener := LSnapshot[I];
      if LListener.Kind <> lkWaterfall then
      begin
        Inc(I);
        Continue;
      end;
      LNext := procedure(const ANextArgs: array of const)
               begin
                 RunFrom(I + 1);
               end;
      try
        LListener.Waterfall(ANextArgs_placeholder(I, AArgs), LNext);
      except
        LAborted := True;
        raise;
      end;
      // if the handler did not call LNext, stop (short-circuit)
      Inc(I);
      Exit;
    end;
  end;

```

Because nested anonymous recursion in Delphi needs a forward-declared procedure variable, implement it as a method-level procedure. The complete, compilable version is given in **Step 3.4b** below.

```pascal
function TEventBus.Waterfall(const AEvent: TEventKey;
  const AArgs: array of const): Boolean;
var
  LSnapshot: TList<TListener>;
  LIndex: Integer;
  LReachedEnd: Boolean;

  procedure RunFrom(AFrom: Integer);
  type
    TNextFn = reference to procedure(const AArgs: array of const);
  var
    I: Integer;
    LCalledNext: Boolean;
    LNext: TWaterfallNext;
    LListener: TListener;
  begin
    I := AFrom;
    while I < LSnapshot.Count do
    begin
      LListener := LSnapshot[I];
      if LListener.Kind <> lkWaterfall then
      begin
        Inc(I);
        Continue;
      end;
      LCalledNext := False;
      LNext := procedure(const AArgs2: array of const)
               begin
                 if LCalledNext then Exit;
                 LCalledNext := True;
                 RunFrom(I + 1);
               end;
      LListener.Waterfall(AArgs, LNext);
      if not LCalledNext then
        Exit;   // short-circuit: handler vetoed
      if LReachedEnd then
        Exit;
      Inc(I);
    end;
    LReachedEnd := True;
  end;

begin
  LSnapshot := nil;
  FLock.Enter;
  try
    if FListeners.TryGetValue(AEvent, LSnapshot) then
      LSnapshot := TList<TListener>.Create(LSnapshot);
  finally
    FLock.Leave;
  end;
  try
    LReachedEnd := False;
    if LSnapshot <> nil then
      RunFrom(0)
    else
      LReachedEnd := True;
    Result := LReachedEnd;
  finally
    LSnapshot.Free;
  end;
end;
```

```pascal
unit Oasis.Context;

{ Oasis framework - the central context. IContext and IPlugin live together
  here because they are mutually recursive (IContext.Plugin takes IPlugin;
  IPlugin.Apply takes IContext) and Delphi forbids a cross-unit interface
  circular uses.

  Isolation model = FIBER: plugins mount on a shared context (shared services +
  events, so DI works across plugins). Each plugin gets its own IEffectScope
  ("fiber") that tracks its side effects, so the plugin can unload independently.
  During Apply, the context's active effect scope is the plugin's fiber; outside
  Apply it is the context-level scope.

  Fork creates an isolated sub-context (own services/events/effects, parent
  chain) for genuine sub-scoping. Dispose: children (reverse) -> fibers (reverse
  mount order) -> context effects. Idempotent. A plugin Apply that raises has its
  partial effects rolled back and the rest keep mounting (fault isolation). }

interface

uses
  System.SysUtils, System.SyncObjs, System.Generics.Collections,
  Oasis.Types, Oasis.Errors, Oasis.Effects, Oasis.Services, Oasis.Events;

type
  IPlugin = interface
    ['{E5F6A7B8-C9D0-4E1F-2A3B-4C5D6E7F8091}']
    function PluginName: string;
    function Inject: TArray<TGUID>;
    procedure Apply(const Ctx: IContext);
    procedure OnUnload(const Ctx: IContext);
  end;

  IContext = interface
    ['{D4E5F6A7-B8C9-4D0E-1F2A-3B4C5D6E7F80}']
    function  Parent: IContext;
    function  Name: string;
    function  IsActive: Boolean;

    { The active effect scope: the fiber of the plugin currently being applied,
      else this context's own scope. }
    function  Effects: IEffectScope;
    function  Services: IServiceRegistry;
    function  Events: IEventBus;

    procedure Effect(const AEffect: TEffectFn);

    { Mount a class plugin on this (shared) context under a fresh fiber. }
    procedure Plugin(APlugin: IPlugin); overload;
    { Mount a closure plugin (no deps, no name metadata). }
    procedure Plugin(const AName: string; const AFn: TProc<IContext>); overload;
    { Mount a closure plugin that returns a top-level disposer (Cordis style). }
    procedure Plugin(const AName: string;
                     const AFn: TFunc<IContext, TDisposer>); overload;

    { Isolated sub-context: own services/events/effects, resolves up the chain. }
    function  Fork(const AName: string = ''): IContext;

    procedure Dispose;
  end;

  TContext = class(TInterfacedObject, IContext)
  strict private
    FName: string;
    FParent: IContext;
    FContextEffects: IEffectScope;
    FServices: IServiceRegistry;
    FEvents: IEventBus;
    FFibers: TList<IEffectScope>;       // per-plugin, mount order
    FChildren: TList<IContext>;         // forks, creation order
    FActiveFiber: IEffectScope;         // set during a plugin Apply
    FDisposed: Boolean;
    procedure MountUnderFreshFiber(const AApply: TProc<IContext>;
                                   const AReturnedDisposer: TFunc<IContext, TDisposer>;
                                   const APluginName: string);
  public
    constructor Create(const AName: string; AParent: IContext = nil);
    destructor Destroy; override;
    function  Parent: IContext;
    function  Name: string;
    function  IsActive: Boolean;
    function  Effects: IEffectScope;
    function  Services: IServiceRegistry;
    function  Events: IEventBus;
    procedure Effect(const AEffect: TEffectFn);
    procedure Plugin(APlugin: IPlugin); overload;
    procedure Plugin(const AName: string; const AFn: TProc<IContext>); overload;
    procedure Plugin(const AName: string;
                     const AFn: TFunc<IContext, TDisposer>); overload;
    function  Fork(const AName: string = ''): IContext;
    procedure Dispose;

    { Generic service convenience (interfaces can't carry generic methods). }
    function  GetService<T: IInterface>: T;
  end;

implementation

{ TContext }

constructor TContext.Create(const AName: string; AParent: IContext);
begin
  inherited Create;
  FName := AName;
  FParent := AParent;
  FContextEffects := TEffectScope.Create;
  if AParent <> nil then
    FServices := TServiceRegistry.Create(AParent.Services)
  else
    FServices := TServiceRegistry.Create(nil);
  // Event bus owns the context-level effect scope; fork's bus parents to parent's.
  if AParent <> nil then
    FEvents := TEventBus.Create(FContextEffects, AParent.Events)
  else
    FEvents := TEventBus.Create(FContextEffects, nil);
  FFibers := TList<IEffectScope>.Create;
  FChildren := TList<IContext>.Create;
end;

destructor TContext.Destroy;
begin
  Dispose;
  FFibers.Free;
  FChildren.Free;
  inherited Destroy;
end;

function TContext.Parent: IContext;
begin
  Result := FParent;
end;

function TContext.Name: string;
begin
  Result := FName;
end;

function TContext.IsActive: Boolean;
begin
  Result := not FDisposed;
end;

function TContext.Effects: IEffectScope;
begin
  if FActiveFiber <> nil then
    Result := FActiveFiber
  else
    Result := FContextEffects;
end;

function TContext.Services: IServiceRegistry;
begin
  Result := FServices;
end;

function TContext.Events: IEventBus;
begin
  Result := FEvents;
end;

procedure TContext.Effect(const AEffect: TEffectFn);
begin
  Effects.Add(AEffect);
end;

procedure TContext.MountUnderFreshFiber(const AApply: TProc<IContext>;
  const AReturnedDisposer: TFunc<IContext, TDisposer>; const APluginName: string);
var
  LFiber: IEffectScope;
  LDisposer: TDisposer;
begin
  LFiber := TEffectScope.Create;
  FActiveFiber := LFiber;
  try
    try
      if Assigned(AApply) then
        AApply(Self);
      if Assigned(AReturnedDisposer) then
      begin
        LDisposer := AReturnedDisposer(Self);
        if Assigned(LDisposer) then
          LFiber.AddCleanup(LDisposer);
      end;
    except
      // Apply raised: roll back this fiber's partial effects, swallow the
      // exception (fault isolation) — the Host surfaces failures via events.
      try
        LFiber.Dispose;
      except
        on EOasisDisposeError do ;
      end;
      Exit;
    end;
  finally
    FActiveFiber := nil;
  end;
  FFibers.Add(LFiber);
end;

procedure TContext.Plugin(APlugin: IPlugin);
var
  LPlugin: IPlugin;
begin
  LPlugin := APlugin;
  MountUnderFreshFiber(
    procedure(C: IContext) begin LPlugin.Apply(C); end,
    nil,
    APlugin.PluginName);
end;

procedure TContext.Plugin(const AName: string; const AFn: TProc<IContext>);
var
  LFn: TProc<IContext>;
begin
  LFn := AFn;
  MountUnderFreshFiber(procedure(C: IContext) begin LFn(C); end, nil, AName);
end;

procedure TContext.Plugin(const AName: string;
  const AFn: TFunc<IContext, TDisposer>);
var
  LFn: TFunc<IContext, TDisposer>;
begin
  LFn := AFn;
  MountUnderFreshFiber(nil, LFn, AName);
end;

function TContext.Fork(const AName: string): IContext;
var
  LForkName: string;
  LFork: IContext;
begin
  if AName = '' then
    LForkName := FName + '.fork'
  else
    LForkName := AName;
  LFork := TContext.Create(LForkName, Self);
  FChildren.Add(LFork);
  Result := LFork;
end;

procedure TContext.Dispose;
var
  I: Integer;
  LFiber: IEffectScope;
  LChild: IContext;
  LFailedMessages: TArray<string>;
  LFailed: Boolean;
begin
  if FDisposed then Exit;
  FDisposed := True;

  // 1. children (reverse creation order)
  for I := FChildren.Count - 1 downto 0 do
  begin
    LChild := FChildren[I];
    try
      LChild.Dispose;
    except
      on E: Exception do
      begin
        LFailed := True;
        SetLength(LFailedMessages, Length(LFailedMessages) + 1);
        LFailedMessages[High(LFailedMessages)] := E.Message;
      end;
    end;
  end;
  FChildren.Clear;

  // 2. fibers (reverse mount order)
  for I := FFibers.Count - 1 downto 0 do
  begin
    LFiber := FFibers[I];
    try
      LFiber.Dispose;
    except
      on E: Exception do
      begin
        LFailed := True;
        SetLength(LFailedMessages, Length(LFailedMessages) + 1);
        LFailedMessages[High(LFailedMessages)] := E.Message;
      end;
    end;
  end;
  FFibers.Clear;

  // 3. context-level effects
  try
    FContextEffects.Dispose;
  except
    on E: Exception do
    begin
      LFailed := True;
      SetLength(LFailedMessages, Length(LFailedMessages) + 1);
      LFailedMessages[High(LFailedMessages)] := E.Message;
    end;
  end;

  if LFailed then
    raise EOasisDisposeError.Create(LFailedMessages);
end;

function TContext.GetService<T>: T;
var
  LInstance: IInterface;
begin
  LInstance := FServices.Get(T);
  Result := LInstance as T;
end;

end.
```

```pascal
  System.SysUtils, System.SyncObjs, System.Generics.Collections,
  Oasis.Types, Oasis.Errors, Oasis.Context, Oasis.Plugin, Oasis.Loader;

const
  EV_HOST_STARTING      : TEventKey = 'host/starting';
  EV_HOST_STARTED       : TEventKey = 'host/started';
  EV_HOST_STOPPING      : TEventKey = 'host/stopping';
  EV_HOST_STOPPED       : TEventKey = 'host/stopped';
  EV_HOST_PLUGIN_FAILED : TEventKey = 'host/plugin_failed';

type
  THost = class
  strict private
    FRoot: IContext;
    FLoaders: TList<IPluginLoader>;
    FPending: TList<IPlugin>;          // plugins waiting on deps
    FPendingLock: TCriticalSection;
    FFailed: TList<string>;
    FStarted: Boolean;
    procedure DoActivate(APlugin: IPlugin);
    procedure RescanPending;
    procedure OnServiceAdded(const AGUID: TGUID);
    function ResolvePlugin(const ASource: string): IPlugin;
  public
    constructor Create;
    destructor Destroy; override;
    function  Root: IContext;
    procedure Use(ALoader: IPluginLoader);
    procedure Mount(APlugin: IPlugin); overload;
    procedure Mount(const ASource: string); overload;
    procedure Start;
    procedure Shutdown;
    function  PendingPlugins: TArray<string>;
    function  FailedPlugins: TArray<string>;
  end;

implementation

{ THost }

constructor THost.Create;
begin
  inherited Create;
  FRoot := TContext.Create('host');
  FLoaders := TList<IPluginLoader>.Create;
  FPending := TList<IPlugin>.Create;
  FPendingLock := TCriticalSection.Create;
  FFailed := TList<string>.Create;
  FRoot.Services.SetOnServiceAdded(OnServiceAdded);
end;

destructor THost.Destroy;
begin
  Shutdown;
  FFailed.Free;
  FPending.Free;
  FPendingLock.Free;
  FLoaders.Free;
  inherited Destroy;
end;

function THost.Root: IContext;
begin
  Result := FRoot;
end;

procedure THost.Use(ALoader: IPluginLoader);
begin
  FLoaders.Add(ALoader);
end;

function THost.ResolvePlugin(const ASource: string): IPlugin;
var
  LKind, LName: string;
  LPos: Integer;
  LLoader: IPluginLoader;
  LFound: Boolean;
  LFactory: TPluginFactory;
begin
  LPos := Pos(':', ASource);
  if LPos > 0 then
  begin
    LKind := Copy(ASource, 1, LPos - 1);
    LName := Copy(ASource, LPos + 1, MaxInt);
  end
  else
  begin
    LKind := '';
    LName := ASource;
  end;

  LFound := False;
  LLoader := nil;
  for LLoader in FLoaders do
  begin
    if (LKind = '') or SameText(LLoader.Kind, LKind) then
    begin
      LFound := True;
      Break;
    end;
  end;
  if not LFound then
    raise EOasisLoaderError.CreateFmt('No loader for kind "%s"', [LKind]);
  LFactory := LLoader.Load(LName);
  Result := LFactory() as IPlugin;
end;

procedure THost.DoActivate(APlugin: IPlugin);
begin
  FRoot.Plugin(APlugin);
end;

function THost.DepsSatisfied(APlugin: IPlugin): Boolean;
var
  LGUID: TGUID;
  LDummy: IInterface;
begin
  for LGUID in APlugin.Inject do
    if not FRoot.Services.Resolve(LGUID, LDummy) then
      Exit(False);
  Result := True;
end;

procedure THost.RescanPending;
var
  I: Integer;
  LPlugin: IPlugin;
  LStillPending: TList<IPlugin>;
begin
  // Take a snapshot under lock, then try to activate.
  FPendingLock.Enter;
  try
    LStillPending := TList<IPlugin>.Create;
    try
      for I := 0 to FPending.Count - 1 do
      begin
        LPlugin := FPending[I];
        if DepsSatisfied(LPlugin) then
        begin
          try
            DoActivate(LPlugin);   // may register more services -> re-entrant rescan
          except
            on E: Exception do
            begin
              FFailed.Add(LPlugin.PluginName);
              FRoot.Events.Emit(EV_HOST_PLUGIN_FAILED, []);
            end;
          end;
        end
        else
          LStillPending.Add(LPlugin);
      end;
      FPending.Clear;
      FPending.AddRange(LStillPending);
    finally
      LStillPending.Free;
    end;
  finally
    FPendingLock.Leave;
  end;
end;

procedure THost.OnServiceAdded(const AGUID: TGUID);
begin
  RescanPending;
end;

procedure THost.Mount(APlugin: IPlugin);
begin
  if DepsSatisfied(APlugin) then
  begin
    try
      DoActivate(APlugin);
    except
      on E: Exception do
      begin
        FFailed.Add(APlugin.PluginName);
        FRoot.Events.Emit(EV_HOST_PLUGIN_FAILED, []);
      end;
    end;
  end
  else
  begin
    FPendingLock.Enter;
    try
      FPending.Add(APlugin);
    finally
      FPendingLock.Leave;
    end;
  end;
end;

procedure THost.Mount(const ASource: string);
begin
  Mount(ResolvePlugin(ASource));
end;

procedure THost.Start;
begin
  if FStarted then Exit;
  FRoot.Events.Emit(EV_HOST_STARTING, []);
  RescanPending;
  FStarted := True;
  FRoot.Events.Emit(EV_HOST_STARTED, []);
end;

procedure THost.Shutdown;
begin
  if not FStarted then Exit;
  FRoot.Events.Emit(EV_HOST_STOPPING, []);
  FStarted := False;
  FRoot.Dispose;
  FRoot.Events.Emit(EV_HOST_STOPPED, []);  // NOTE: root disposed; see correction 6.5b
end;

function THost.PendingPlugins: TArray<string>;
var
  I: Integer;
begin
  SetLength(Result, FPending.Count);
  for I := 0 to FPending.Count - 1 do
    Result[I] := FPending[I].PluginName;
end;

function THost.FailedPlugins: TArray<string>;
begin
  Result := FFailed.ToArray;
end;

end.
```
